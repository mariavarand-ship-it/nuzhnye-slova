Нужные слова — готовое веб-приложение

Файлы:
- index.html — главная страница
- style.css — внешний вид
- script.js — логика приложения и 300 фраз
- manifest.json — настройки PWA
- service-worker.js — базовое офлайн-кэширование

Как открыть:
1. Распакуй архив.
2. Открой index.html двойным кликом.

Как поставить на iPhone:
1. Выложи все файлы на GitHub Pages, Netlify или Vercel.
2. Открой ссылку в Safari на iPhone.
3. Поделиться → Добавить на экран «Домой».

Особенности:
- приложение спрашивает имя из детства;
- имя сохраняется в браузере;
- три кнопки: Поднять настроение, Совет дня, Похвалить;
- по 100 фраз на каждую кнопку;
- фразы не повторяются, пока не закончатся все 100 в своей категории.
